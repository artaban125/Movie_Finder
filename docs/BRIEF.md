너는 웹서비스 제품기획자야.
아래 아이디어를 실제 출시 가능한 제품 관점에서 PRD로 작성해줘.

# 서비스 아이디어

영화 정보를 영화명, 감독명, 개봉일로 검색하고, 오늘자 박스오피스를 확인하는 웹서비스

# 대상 사용자

보고 싶은 영화가 있는데 영화 정보가 잘 기억나지 않는 사용자

# 사용자가 겪는 문제

* 오늘 영화를 보고 싶은데 박스오피스 순위를 모른다.
* 영화 제목이 기억나지 않는데 감독의 이름이나 개봉일은 알고 있다.
* 좋아하는 영화의 주연 배우, 역할 등 세부사항은 알기 어렵다.
* 좋아하는 영화의 목록을 항상 기억해두기 어렵다.

# 핵심 가치

영화 제목이나 감독의 이름, 개봉일을 통해 원하는 영화 제목을 빠르게 찾고, 해당 영화의 세부 정보를 알 수 있게 한다.

# 주요 기능

* 오늘의 박스오피스 Top 10
* 영화 검색기능 (영화 제목으로)
* 영화 검색기능 (감독 이름으로)
* 영화 검색기능 (영화 개봉일로)
* 검색한 영화의 세부정보 보기
* 즐겨찾기 추가/삭제
* 서비스 소개

# MVP에 포함할 화면/기능

* 박스오피스 Top 10 화면
* 영화 제목으로 영화 검색 기능
* 감독 이름으로 영화 검색 기능
* 개봉일로 영화 검색 기능
* 소개 화면

# 박스오피스 Top 10 화면에 포함할 내용

* 영화 제목, 영화 포스터 이미지, 감독

# 검색된 영화 목록 화면에 포함할 내용

* 영화명(국문), 영화명(영문), 제작연도, 개봉일, 영화유형, 영화장르, 영화감독, 영화감독명, 제작사, 제작사명

# 선택한 영화 세부 정보 화면에 포함할 내용

* 영화명(국문), 영화명(영문), 제작연도, 상영시간, 개봉연도, 제작상태, 영화유형, 제작국가명, 장르명, 감독, 감독명, 감독명(영문), 배우, 배우명, 배우명(영문), 배역명, 배역명(영문), 상영형태 구분, 상영형태 구분(영문), 상영형태명, 심의정보, 심의번호, 관람등급, 참여 영화사, 참여 영화사 코드, 참여 영화사명, 참여 영화사명(영문), 참여 영화사 분야명, 스텝, 스텝명, 스텝명(영문), 스텝역할명

# MVP 완성 후 추가 개발할 기능

* 영화 감독의 세부 정보 보여주기
* 즐겨찾기 추가/삭제

# 제외할 기능

* 로그인
* 회원가입
* 리뷰
* 별점
* 결제
* 관리자 화면
* 알림

# 사용할 데이터

공공데이터 API를 사용한다.
요청주소 및 관련 정보는 별도 제공하겠음.
서버에서 API를 호출해 박스오피스, 영화 정보, 영화 세부 정보를 가져오고, 가져온 데이터를 SQLite DB에 저장한 뒤 서비스에서 사용한다.
프론트엔드는 외부 API를 직접 호출하지 않고, FastAPI 서버가 제공하는 API만 호출한다.

# 기술 고려사항

* 프론트엔드: React
* 백엔드: FastAPI
* DB: SQLite
* 지도: Leaflet
* 즐겨찾기: localStorage

# 성공 기준

MVP 기준으로는 박스오피스 Top 10 목록을 보여주고, 사용자가 조건에 따라 영화를 검색하고, 검색된 목록에서 영화의 상세 정보를 확인할 수 있으면 성공으로 본다.

추가 개발까지 완료한 경우, 관심 있는 영화를 즐겨찾기에 저장하고 다시 열어볼 수 있고, 감독의 세부 정보를 확인할 수 있으면 성공으로 본다.
