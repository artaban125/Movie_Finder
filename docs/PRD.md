# 영화 검색 및 박스오피스 조회 웹서비스 PRD

## 1. 제품 개요

### 제품명(가칭)

Movie Finder

### 서비스 소개

Movie Finder는 사용자가 영화 제목, 감독명, 개봉일을 이용하여 원하는 영화를 쉽게 검색하고, 오늘의 박스오피스 Top 10과 영화의 상세 정보를 확인할 수 있는 웹서비스이다.

사용자는 기억이 잘 나지 않는 영화도 다양한 조건으로 검색할 수 있으며, 검색 결과에서 영화의 상세 정보(배우, 감독, 제작사, 상영정보 등)를 확인할 수 있다.

서비스는 공공데이터 API를 활용하여 영화 및 박스오피스 정보를 수집하며, FastAPI 서버가 데이터를 저장·가공하여 React 프론트엔드에 제공한다.

MVP에서는 검색 및 조회 기능에 집중하고, 이후 즐겨찾기와 감독 상세 조회 기능을 추가한다.

# 2. 대상 사용자

## 주요 사용자

- 오늘 볼 영화를 찾는 일반 사용자
- 영화 제목이 기억나지 않는 사용자
- 감독 이름만 기억하는 사용자
- 개봉일만 기억하는 사용자
- 배우, 배역, 제작사 등 영화 정보를 확인하고 싶은 사용자

## 사용자 특성

- 회원가입 없이 바로 사용하고 싶다.
- 원하는 영화를 빠르게 찾고 싶다.
- 영화 정보를 한 곳에서 확인하고 싶다.

# 3. 문제 정의

## 문제 1. 오늘 인기 있는 영화를 알기 어렵다.

오늘 가장 많이 관람하는 영화를 쉽게 확인하기 어렵다.

## 문제 2. 영화 제목이 기억나지 않는다.

영화 제목은 기억나지 않지만 감독 이름이나 개봉일만 기억하는 경우 원하는 영화를 찾기 어렵다.

## 문제 3. 영화의 세부 정보를 찾기 번거롭다.

배우, 배역, 제작사, 상영시간, 심의정보 등을 여러 사이트에서 찾아야 한다.

## 문제 4. 좋아하는 영화를 저장하기 어렵다.

관심 있는 영화를 기억하거나 다시 찾기 어렵다.

# 4. 주요 기능

## 4.1 오늘의 박스오피스 Top 10

### 설명

오늘의 박스오피스 Top 10을 캐러셀(Carousel) 형태로 제공한다.

### 제공 정보

- 박스오피스 순위
- 영화 포스터
- 영화 제목
- 감독명

### 동작

- 메인 화면 상단에 배치
- 한 화면에 영화 카드 **5개** 표시
- 좌우 방향 자동 슬라이드
- **2초 간격(설정 가능: 1~2초)** 자동 재생
- 마지막까지 표시 후 처음부터 반복(Loop)
- 좌우 이동 버튼 제공
- 마우스 오버 시 자동 재생 일시 정지
- 영화 클릭 시 상세 정보 팝업 표시
