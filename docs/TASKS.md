# Movie Finder 작업 목록

체크리스트는 `docs/DEVELOPMENT_PLAN.md`와 `docs/PRD.md`를 기준으로 한다.  
프로젝트 생성·conda·scaffold·health 연결은 제외하고, **기능 구현 단위**만 포함한다.
